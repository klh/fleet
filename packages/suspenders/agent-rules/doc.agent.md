## DELTA CONTRACT

1. **Per-package AGENTS.md files are the canonical docs**; the root
   AGENTS.md is stack-wide law. Docs changes update the canonical copy,
   never a duplicate.
2. **Preservation over consolidation** — unless the item explicitly says
   dedupe, historical/decision records stay (dated); condensation keeps
   the evidence trail and links to the owning record.
3. **Link scans carry receipts**: command + counts + zero broken targets,
   banked on the item.
4. **LLM outputs are leads, not facts.** First-tier sources for claims;
   never publish unverified claims — mark or omit.
5. **Markdown is prettier-formatted** on save; re-read after bulk writes.
6. **Never comment on Jira/PRs/trackers** unless the owner asked for that
   exact comment.
