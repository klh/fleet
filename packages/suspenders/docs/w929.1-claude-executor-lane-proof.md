## Findings

1. **Fresh `CLAUDE_CONFIG_DIR` is the hermetic-leg recipe** — verified
   live: headless `-p` runs with no onboarding wall (JSON result +
   `session_id` printed, config dir stays empty of fleet hooks). One
   caveat: an auth-failing child ignores the 90 s `timeoutMs` kill and
   retried for ~3 min before exiting — size `--timeout` accordingly when
   the key is unproven.
2. **`unrecognized_model` stderr warning is cosmetic** — the CLI flags
   non-Anthropic model ids client-side (`query_source: "sdk"`) but the
   request fires and completes; both legs returned 0.
3. **Resume semantics** — `--resume <sid> --fork-session` on 2 legs of the
   same front slug; leg 2's reply carried leg 1's token. The fresh config
   dir holds the session store, so resume resolves inside the probe's own
   home — no real `~/.claude` writes.
