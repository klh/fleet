## What landed

The verb landed on main 2026-10-07 (ccc951b, merged into this branch):
`klh-local dns-reconcile <name>` — DNS-only registry reconcile under the
registry lock. Verifies the ACTIVE Caddy route (host → target) via the
read-only admin API before touching DNS; refuses on mismatch or
unreachable admin API (DNS unchanged, exit 1). Keeps an exact live
claimant (`unchanged`); otherwise spawns a fresh claim and publishes the
pid only after the new process registers its exact argv (`reconciled`);
a failed publish SIGTERMs only the new claimant. No reload, no fragment
writes — Caddy auth/listeners/routes untouched. The resident runner
`dns-serve` (LaunchAgent `com.suspenders.local-dns`) drives the same
pass every 30s and releases only its own verified claims on shutdown.

This commit closes the docs gap: `packages/local/SPEC.md` now carries
both verbs in the verb list + contract sections (`dns-serve`,
`dns-reconcile`), matching README line 85.
