## Verdict

- 65 Trove rows · 35 match a vendored catalog entry · 30 gaps.
- Every Vercel catalog target is retained (78/78 wired or gated; the
  `universal` pseudo-agent is skills-package-only and stays excluded
  from the target list) — `listTargets()` returns the full vendored
  breadth, gating never prunes. Pinned by test
  `fleet-targets.test.ts` "retention record" case (this commit).
- The 30 gaps are Terminal-Trove-only agents with no skills-CLI catalog
  entry. Per the parent mission the skills catalog is the single
  source — gaps become Fleet targets only after upstream skills CLI
  support lands (or via an explicit local overlay decision), not by
  silent forking of the vendor list. GAPS_FOUND count recorded here;
  none of the 30 blocks any enabled executor today.
